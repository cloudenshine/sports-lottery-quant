# 每日研究运行说明

本项目已接通真实公开数据采集、赛前登记、赛果修订、模型评分、数学假设收益和固定窗口检验。此流程不创建真实投注。

## 已启用的定时任务

Codex 当前任务的 heartbeat 自动化：`体彩科学研究：每日采集与前瞻验证`，ID `automation`，状态 ACTIVE。

本机时区已确认是 China Standard Time / UTC+08:00。每天北京时间 **10:30、18:30、23:30** 执行 `npm run research:daily`，随后运行 `npm run build`。官方原文每满24小时重新抓取，其余时段读取已归档版本。无新事件及已知未变化的降级保持安静；新失败、恢复、规则变更、结算与撤回、研究窗口结束才通知。

这是本机 Codex 调度，需要本机和 Codex 能够运行并联网。没有部署到远程无人值守服务器；当前已验证的是命令真实执行与调度配置 ACTIVE，首次计划时刻的实际触发尚待发生。

## 命令

| 命令 | 用途 |
|---|---|
| `npm run research:daily` | 公开联网采集、同批次赛前预测、结算/撤回、规则监控、看板快照 |
| `npm run research:models` | 离线足球历史回测；按来源族分开，保存精确输入快照 |
| `npm run research:numbers` | 离线双色球/大乐透四种策略、相同预算与固定种子的比较 |
| `npm run build` | 生成数字彩、竞技彩票和研究工作台三个单文件页面 |
| `npm run verify` | 静态语法、全部测试、数字彩科学回放；不请求网络 |
| `npm run serve` | 本机 `http://127.0.0.1:8080/research.html` |

每日命令退出码：0=可用源正常，1=运行错误/部分记录失败，2=数据源或规则站降级但有效记录已经保留。当前已知降级是 football-data 原站 HTTP 503，不能因此把其他成功来源判作未采集。

## 证据与恢复

- `data/research/raw/`：赛程、赔率、赛果响应原始字节，以 SHA-256 命名；`cache/` 保存逐源最近有效视图。
- `data/research/rules/`：官方原文、每次请求记录、精确字节复核收据。原文哈希变化不自动修改规则合同；首次11份基线已阅，北单完整结算及传统足彩完整异常合同仍分别待证。
- `protocol-receipts/`：首轮预测前写入协议、注册时间与实际执行管线哈希。数据解析器、模型、账本、裁决和入口改动必须使用新的协议标识，旧档案保留。
- `forecast-batches/`：同场全部模型的原始信息批次。中断后只能重放同批输入，不能拿后来的赔率补成同场比较。
- `ledger/`：不可覆盖的预测、结果版本、结算与撤销。重新运行不会改变原预测；来源撤回赛果会移除其评分和收益，严格更新的最终结果才能恢复。
- `runs/`：每次真实运行的新增记录、错误、数据数量和裁决证据。`last-failure.json` 若存在须与成功运行时间比较，它保留故障历史，不代表后来仍然失败。
- `dashboard.json/js`：供应用读取的最新摘要。完整历史逐场模型输出保留在 `docs/testing/model-tournament.json`，不会把重建回测写入前瞻账本。

先备份整个 `data/research` 再进行人工迁移。不得删除账本来重置不利结果。普通死 PID 的运行锁由独占获取守卫恢复；如果获取守卫本身被中断遗留，应读取锁中 PID、确认该进程确实不存在后归档恢复，不能按时间过久就删除活进程锁。损坏的提交文件必须保留并诊断，不能补造成功记录。

## 科学合同

足球实验输出主/平/客概率，主评分为 `-log(p[实际结果])`，辅评分为三分类 Brier。历史基准、收缩泊松、Elo、市场去水、市场幂变换、组合模型与均匀随机共同参赛。球队强度只能使用预测前已获取的同来源同联赛赛果；历史回测缺失真实发表时间的假设另行标注。

回测同时比较每场最高概率和 `max(p × decimalOdds) > 1.05` 才选择的策略。否则保留现金，收益为0；并列选项按等概率选择的数学期望计算。每场预算上限相同，报告同时列出实际投入、全机会预算、随机与市场对照。赔率去水本身只是基线，不是已发现市场定价错误。

前瞻 v1 在注册后的固定90日窗口采样，每个来源/模型要求至少500场具有相同信息批次的配对赛事。未到窗口结束不进行显著性裁决；缺赛果等待，但不延长纳入赛事的时间窗。检验同时要求市场概率评分改善、净收益下界为正、相对随机的收益改善，并校正多模型比较。已判定的单个来源/模型也立即锁定，不能随每日涨跌反复挑选通过时机。

历史收益使用显式固定十进制赔率数学假设；欧洲历史开盘价、国内二手公开报价、官方出票锁定赔率和可兑现奖金是不同证据。当前没有真实成交凭证，不把纸面收益标成实际收益。
