## 科学对照

报告：`scientific-evaluation.json`，命令 `npm run science:evaluate`。每彩种最近100期、每期5注、3个固定种子；每个种子累计预算1000元。每期先汇总种子，再作区块bootstrap 95%区间，避免把同期开奖的不同种子当独立观测。

当前基线结果（金额是当前奖表情景，并非实际历史收益）：

| 彩种 | 策略平均情景净收益 | 均匀随机平均情景净收益 | 每期收益差95%区间 |
|---|---:|---:|---:|
| 双色球 | -743.33元 | -686.67元 | [-2.90, 1.68]元 |
| 大乐透 | -791.67元 | -698.33元 | [-2.35, 0.20]元 |

这组结果不支持稳定提高收益的结论。探索性测试未校正多策略筛选，也不能用100期样本估计稀有头奖尾部。体彩没有真实、带赛前时间戳的预测、市场基线和已结算赛果，因此返回 `INSUFFICIENT_DATA`；已提供Brier/log-loss评分接口，尚无实测预测优势。
